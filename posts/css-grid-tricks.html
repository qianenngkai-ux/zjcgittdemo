Grid 布局的五个实用技巧

2026-09-10 · CSS · 8 分钟

Flexbox 解决一维排布，Grid 解决二维。但多数人对 Grid 的用法停留在 grid-template-columns: repeat(3, 1fr)，没用上它真正省事的那几个特性。

1. auto-fit 代替媒体查询

不需要为「平板上两列、手机上单列」写断点，交给浏览器算：

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(240px, 1fr));
  gap: 1rem;
}

容器放得下几个 240px 的列，就排几列。窗口一缩，列数自动减少。

2. 负网格线

-1 永远代表最后一条网格线，不管实际有多少列。这让「撑满整行」不依赖具体的列数：

.full-bleed {
  grid-column: 1 / -1;
}

3. 用 gap 代替 margin

gap 只作用于项目之间，不会在最外侧产生多余间距。以前用 margin-right 再给最后一个子元素写 :last-child { margin-right: 0 } 的做法可以彻底删掉。

4. 网格区域命名

用 grid-template-areas 画 ASCII 图，比记行列号可读得多，改版式时也只需要挪动那几个单词：

.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
  grid-template-columns: 200px 1fr;
}

.layout > header { grid-area: header; }
.layout > aside  { grid-area: sidebar; }
.layout > main   { grid-area: main; }

5. minmax 与 auto 配合

侧边栏固定宽度在窄屏会挤扁主内容。minmax(200px, auto) 让它有下限也能撑开：

grid-template-columns: minmax(200px, auto) 1fr;

小结

这几个特性都不需要 JavaScript，也不需要预处理器。Grid 的能力比大多数人日常用到的多得多。
